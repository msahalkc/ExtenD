Get ExtenD

Get the code

Install Xcode and XcodeGen (brew install xcodegen), clone the repo, run xcodegen generate.

Set your team

Copy Config/Local.xcconfig.example to Local.xcconfig and add your team ID. A free Apple ID works.

Run on your Mac

Run ExtenDMac, then allow Screen Recording and Accessibility in System Settings.

Run on your iPad

Turn on Developer Mode, run ExtenDPad, and accept the matching code on both screens.

No prebuilt downloads yet. With a free Apple ID, the iPad app stops opening after 7 days: run it from Xcode again to renew.

Questions

How is this different from Sidecar?

Sidecar needs the Mac and iPad signed in to the same Apple Account. ExtenD doesn't: you pair the two devices directly with a code. It also adds touch gestures beyond Sidecar's Pencil-first input.

Does it work over Wi-Fi?

Yes, on the same local network. USB-C gives the lowest latency; Wi-Fi takes over automatically when you unplug, and USB takes back over when you plug in again.

Can I use multi-touch apps on the Mac?

macOS has no public way to receive touches from another device, so ExtenD translates them into clicks, scrolls, drags and shortcuts. Pinch-to-zoom works in apps that zoom with ⌘+ and ⌘−.

Why isn't it on the App Store?

Creating a virtual display relies on a macOS interface Apple doesn't publish, so the Mac app can't be on the Mac App Store. It may also need updating after major macOS releases.

Does it collect any data?

No. There are no accounts, servers or analytics, in the apps or on this site. The only traffic is between your own Mac and iPad, encrypted end to end.
